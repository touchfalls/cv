# cv

Простая команда для Mac, которая конвертирует видео и фото.

- **Видео:** MKV ⇄ MP4 за секунды, даже если файл весит 50 ГБ. Качество не теряется.
- **Сжатие видео:** уменьшает размер файла с помощью встроенного в Mac видеочипа.
- **Обрезка видео:** например, «оставить первые 30 минут».
- **Фото:** HEIC (с iPhone), PNG, WebP, AVIF, JPEG → лёгкий JPEG.

## Установка

Нужны [Homebrew](https://brew.sh) и Go.

```sh
brew install ffmpeg go
go install github.com/touchfalls/cv@latest
echo 'export PATH="$HOME/go/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

Проверка: наберите `cv`, должна появиться подсказка.

## Как пользоваться

### Видео

```sh
cv фильм.mkv          # сделает фильм.mp4
cv фильм.mp4          # сделает фильм.mkv
```

Видео не пересжимается, просто перекладывается в другой «контейнер». Поэтому это быстро и без потерь.
Все звуковые дорожки и субтитры сохраняются.

**Сжать видео** (файл станет меньше, но это дольше):

```sh
cv -c фильм.mkv            # обычное качество
cv -c -q 40 фильм.mkv      # меньше файл, хуже картинка
cv -c -q 75 фильм.mkv      # больше файл, лучше картинка
```

**Обрезать видео:**

```sh
cv -to 30m фильм.mkv               # первые 30 минут
cv -from 1h -to 1h30m фильм.mkv    # с 1:00:00 до 1:30:00
cv -from 10m фильм.mkv             # с 10-й минуты до конца
```

Время можно писать так: `30m`, `1h20m`, `90s`, `30:00`, `1:20:00`.
Обрезанный файл получит в имени `.cut`, например `фильм.cut.mp4`.

### Фото

```sh
cv фото.heic               # сделает фото.jpg
cv ~/Pictures/отпуск       # все фото в папке
cv -max 1920 -q 70 ./фото  # поменьше и полегче
```

По умолчанию фото уменьшаются до 2560 px по длинной стороне (маленькие не увеличиваются), качество 80.

## Все настройки

| Флаг | Что делает | По умолчанию |
|---|---|---|
| `-c` | сжать видео | выкл. |
| `-q` | качество от 1 до 100 | видео 60, фото 80 |
| `-from` | начало обрезки видео | с начала |
| `-to` | конец обрезки видео | до конца |
| `-max` | макс. размер фото в px, `0` — не уменьшать | 2560 |
| `-o` | папка, куда класть результат | рядом с оригиналом |

Флаги пишутся **перед** файлами: `cv -c фильм.mkv`, а не `cv фильм.mkv -c`.

## Полезно знать

- Оригиналы никогда не удаляются и не перезаписываются.
- Если результат уже есть, файл пропускается. Можно спокойно запускать повторно.
- Если нажать Ctrl+C, недоделанный файл удалится сам.
- Субтитры-картинки с Blu-ray (PGS) в MP4 не помещаются и пропускаются (будет предупреждение).
- Обрезка без `-c` начинается с ближайшего «ключевого кадра», то есть может захватить пару секунд раньше. Нужна точность? Добавьте `-c`.
