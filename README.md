# cv

Простая команда для Mac, которая конвертирует видео и фото.

- **Видео:** MKV ⇄ MP4 за секунды, даже если файл весит 50 ГБ. Качество не теряется.
- **Сжатие видео:** уменьшает файл с помощью встроенного в Mac видеочипа. Можно уменьшить и разрешение (4K → 1080p).
- **Обрезка и склейка видео:** «оставить первые 30 минут» или «склеить три серии в одну».
- **Лишние дорожки:** оставить только русскую озвучку, убрать субтитры.
- **Фото:** HEIC (с iPhone), PNG, WebP, AVIF, JPEG → лёгкий JPEG, HEIC, AVIF или WebP.
- **Приватность:** может удалить из фото и видео GPS-координаты и данные о камере.

## Установка

Нужен [Homebrew](https://brew.sh). Одна команда:

```sh
brew install touchfalls/tap/cv
```

Homebrew сам поставит всё нужное (ffmpeg и прочее). Проверка: наберите `cv`, должна появиться подсказка.

Обновление: `brew upgrade cv`.

## Видео

```sh
cv фильм.mkv          # сделает фильм.mp4
cv фильм.mp4          # сделает фильм.mkv
```

Видео не пересжимается, а просто перекладывается в другую «обёртку» (контейнер). Поэтому это быстро и без потерь.
Все звуковые дорожки и субтитры сохраняются.

### Сжать

```sh
cv -c фильм.mkv            # обычное качество
cv -c -q 40 фильм.mkv      # меньше файл, хуже картинка
cv -c -q 75 фильм.mkv      # больше файл, лучше картинка
cv -res 1080 фильм.mkv     # уменьшить до 1080p (сильнее всего экономит место)
cv -res 720 фильм.mkv      # до 720p
```

Если сжатый файл вдруг получится больше оригинала, cv его не сохранит и скажет об этом.

### Обрезать

```sh
cv -to 30m фильм.mkv               # первые 30 минут
cv -from 1h -to 1h30m фильм.mkv    # с 1:00:00 до 1:30:00
cv -from 10m фильм.mkv             # с 10-й минуты до конца
```

Время можно писать так: `30m`, `1h20m`, `90s`, `30:00`, `1:20:00`.
Обрезанный файл получит в имени `.cut`, например `фильм.cut.mp4`.

### Убрать лишние дорожки

```sh
cv -audio rus фильм.mkv              # оставить только русскую озвучку
cv -audio rus,eng -subs rus фильм.mkv
cv -subs none фильм.mkv              # убрать все субтитры
```

Язык можно писать коротко: `ru`, `en`. Если нужной дорожки нет, cv оставит все и предупредит.

### Склеить

```sh
cv -join серия1.mkv серия2.mkv серия3.mkv    # сделает серия1.joined.mkv
```

Файлы склеиваются в том порядке, в каком перечислены, без перекодирования.
Склеить получится только «одинаковые» файлы: те же кодеки, разрешение и набор дорожек
(например, серии одного сериала из одного источника).

## Фото

```sh
cv фото.heic               # сделает фото.jpg
cv ~/Pictures/отпуск       # все фото в папке
cv -max 1920 -q 70 ./фото  # поменьше и полегче
cv -f webp ./фото          # в WebP (для сайтов)
cv -f avif ./фото          # в AVIF (самые маленькие файлы)
cv -strip ./фото           # удалить GPS и данные о камере
```

По умолчанию фото уменьшаются до 2560 px по длинной стороне (маленькие не увеличиваются), качество 80.

| Формат | Чем хорош |
|---|---|
| `jpg` (по умолчанию) | открывается везде |
| `heic` | как на iPhone: меньше JPEG, хорошо работает на технике Apple |
| `webp` | для сайтов, примерно на треть меньше JPEG |
| `avif` | самый компактный, но открывается не везде |

## Все настройки

| Флаг | Что делает | По умолчанию |
|---|---|---|
| `-c` | сжать видео | выкл. |
| `-q` | качество от 1 до 100 | видео 60, фото 80 |
| `-res` | уменьшить видео до 1080, 720… (включает сжатие) | не уменьшать |
| `-from` | начало обрезки видео | с начала |
| `-to` | конец обрезки видео | до конца |
| `-audio` | какие озвучки оставить: `rus`, `rus,eng`, `none` | все |
| `-subs` | какие субтитры оставить: `rus`, `none` | все |
| `-join` | склеить видео в одно | выкл. |
| `-f` | формат фото: `jpg`, `heic`, `avif`, `webp` | `jpg` |
| `-max` | макс. размер фото в px, `0` — не уменьшать | 2560 |
| `-strip` | удалить GPS, модель камеры и прочие метаданные | выкл. |
| `-o` | папка, куда класть результат | рядом с оригиналом |
| `-version` | показать версию | |

Флаги можно писать где угодно: и `cv -c фильм.mkv`, и `cv фильм.mkv -c`.

## Полезно знать

- Оригиналы никогда не удаляются и не перезаписываются.
- Если результат уже есть, файл пропускается. Можно спокойно запускать повторно.
- Если нажать Ctrl+C, недоделанный файл удалится сам.
- В конце cv пишет итог: сколько файлов сделано и сколько места сэкономлено.
- Субтитры-картинки с Blu-ray (PGS) в MP4 не помещаются и пропускаются (будет предупреждение).
- Обрезка без `-c` начинается с ближайшего «ключевого кадра», то есть может захватить пару секунд раньше. Нужна точность? Добавьте `-c`.
- В WebP метаданные (и GPS) не переносятся никогда. В HEIC/AVIF с `-strip` пропадает прозрачность у PNG.
